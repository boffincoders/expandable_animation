Drag-to-dismiss lets users close a fullscreen view the way they opened it: directly, with their finger. It is on by default in ExpandableAnimation.

How the gesture works

  1. The user drags the expanded view downward. It follows the finger (scaled by dragResistance), shrinks toward minScale, rounds its corners and the background fades.
  2. On release it dismisses if it was dragged at least dismissThreshold × its height, or flung downward faster than velocityThreshold.
  3. Otherwise it springs back, carrying the release velocity. A fast upward fling always cancels.
  4. When it dismisses, the collapse starts from exactly where the finger left it.
ExpandableAnimation(
  enableDragToDismiss: true,
  gestureConfig: const ExpandableAnimationGestureConfig(
    dismissThreshold: 0.2,
    velocityThreshold: 700,
    minScale: 0.85,
    dragResistance: 0.6,
    enableHapticFeedback: true,
  ),
  expandedBuilder: (context) => const DetailsPage(),
  child: const SummaryCard(),
)

Scrollable content

Vertical lists inside the expanded view keep scrolling normally. The dismiss gesture only starts when a list that is already at its top is pulled further down, and it hands control back if the user drags up again. Horizontal scrollables, such as a PageView, are never affected. Set dismissFromScrollableContent: false to dismiss only from non-scrolling areas.

Preventing a dismissal

PopScope(
  canPop: !hasUnsavedChanges,
  onPopInvokedWithResult: (didPop, result) {
    if (!didPop) showDiscardDialog(context);
  },
  child: const EditForm(),
)

With canPop: false, drags spring back and background taps, Escape and the back button are ignored; controller.collapse() still works.

Observing the drag

ListenableBuilder(
  listenable: controller,
  builder: (context, _) => Opacity(
    opacity: controller.isDragging ? controller.progress : 1,
    child: const Toolbar(),
  ),
)
