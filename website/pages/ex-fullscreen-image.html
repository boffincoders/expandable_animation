Photo grids feel best when a thumbnail grows straight into the full image and shrinks back into its exact cell. The key is to expand the surface to the image's final on-screen rectangle, not the whole screen, so the picture itself morphs without any cross-fade offset.

Expand to the image bounds

Rect fitSquare(ExpandedBoundsContext bounds) {
  final area = bounds.safeArea;
  final side = area.shortestSide;
  return Rect.fromCenter(center: area.center, width: side, height: side);
}

ExpandableAnimation(
  mode: const ExpandableAnimationMode.custom(fitSquare),
  borderRadius: BorderRadius.circular(10),
  backgroundOpacity: 1, // solid black behind the photo
  gestureConfig: const ExpandableAnimationGestureConfig(
    minScale: 0.7,
    dragResistance: 1, // the photo follows the finger exactly
  ),
  semanticLabel: 'Open photo',
  expandedBuilder: (context) => PhotoViewer(photo: photo),
  child: ClipRRect(
    borderRadius: BorderRadius.circular(10),
    child: Image(image: photo.thumbnail, fit: BoxFit.cover),
  ),
)

For non-square photos, compute the rectangle from the image's aspect ratio inside bounds.safeArea, the same way BoxFit.contain would.

Back navigation

The viewer is a modal route: the Android back button, Escape and a tap on the black background (dismissOnBackgroundTap) close it, and focus returns to the thumbnail. If the grid scrolled or the thumbnail was removed while the viewer was open, the image returns to its new position or fades out in place.

Zoom

Pinch-to-zoom inside the viewer (InteractiveViewer) competes with the drag gesture. Built-in zoom coordination is on the roadmap; until then, set enableDragToDismiss: false for zoomable viewers and rely on the close button, background tap and back button.
