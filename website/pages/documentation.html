The ExpandableAnimation widget

ExpandableAnimation shows its child in place. When expanded, the child is hidden in place (keeping its size), and a morphing surface animates from the child's bounds to the expanded bounds while the collapsed and expanded content cross-fade.

Expansion modes

// Fill the screen (default). useSafeArea stops at notches and system bars.
const ExpandableAnimationMode.fullscreen(useSafeArea: false)

// A centered panel: inset by margin, capped at maxSize, above the keyboard.
const ExpandableAnimationMode.dialog(
  margin: EdgeInsets.all(24),
  maxSize: Size(560, 720),
)

// Partial expansion anchored to the bottom edge.
const ExpandableAnimationMode.sheet(heightFactor: 0.6, maxWidth: 640)

// Anything else: compute a Rect from the overlay size, safe area,
// keyboard insets and the source bounds.
ExpandableAnimationMode.custom(
  (bounds) => Alignment.topRight.inscribe(
    const Size(360, 480),
    bounds.safeArea.deflate(16),
  ),
)

The expanded bounds are recomputed on every layout, so they follow window resizes and orientation changes. The source bounds are measured again when collapsing, so the view returns to wherever the child is now.

Controller and lifecycle

final controller = ExpandableAnimationController();

await controller.expand();   // completes when expanded or interrupted
await controller.collapse(); // completes when collapsed or interrupted
controller.toggle();

controller.phase;       // ExpandableAnimationPhase.collapsed / expanding / expanded / collapsing
controller.progress;    // 0.0 – 1.0
controller.isDragging;  // true during a dismiss drag
controller.isAttached;  // attached to a mounted widget

// Dispose it in the State that created it.
controller.dispose();

Without a controller, the widget creates one. Read it from either subtree with ExpandableAnimation.of(context). Interruptions reverse from the current position: collapse() during an expansion, or expand() (or a tap) during a collapse.

Duration, curves and spring physics

ExpandableAnimation(
  duration: const Duration(milliseconds: 450),
  curve: Curves.easeOutCubic,
  reverseCurve: Curves.easeInCubic,
  // ...or a spring, which replaces both:
  physics: const ExpandableAnimationPhysics.spring(
    stiffness: 200,
    dampingRatio: 0.75, // below 1.0 overshoots
  ),
  // ...
)

Presets: ExpandableAnimationPhysics.smooth (no overshoot), bouncy and snappy. The collapse always uses a critically damped version of the spring so the view never shrinks past its source. SpringCurve is exported too, if you want spring-shaped curves elsewhere.

Drag-to-dismiss and gestures

See the dedicated drag-to-dismiss guide. In short: drag down to dismiss; vertical scrollables scroll until they reach the top; PopScope can veto; thresholds live in ExpandableAnimationGestureConfig.

A drag that dismisses the view hands its speed to the collapse (matchReleaseVelocity, on by default). For zoomable content such as photos, wrap it in ExpandableAnimationZoomable: pinch, pan and double-tap zoom that pause dismissal while zoomed in. See the fullscreen image guide.

Custom transitions

The transitionBuilder receives the clamped progress animation and the two layers. Each layer fills the surface, laid out at its natural size and scaled to the surface width:

ExpandableAnimation(
  transitionBuilder: (context, animation, collapsed, expanded) {
    return Stack(
      fit: StackFit.expand,
      children: [
        FadeTransition(
          opacity: ReverseAnimation(CurvedAnimation(
            parent: animation,
            curve: const Interval(0, 0.3),
          )),
          child: collapsed,
        ),
        FadeTransition(
          opacity: CurvedAnimation(
            parent: animation,
            curve: const Interval(0.3, 0.7),
          ),
          child: expanded,
        ),
      ],
    );
  },
  // ...
)

Navigation, themes and state

  • The expanded view is a modal route on the root navigator (configurable). The back button, Escape and Navigator.pop collapse it.
  • Inherited themes (Theme, CupertinoTheme, IconTheme, DefaultTextStyle and others) are captured at the source and applied to the expanded view.
  • The child and the expanded content are separate widget instances. Keep shared state, such as music playback, outside both — see the music player example.
  • Rebuilding the parent rebuilds the expanded view with the new expandedBuilder.
  • If the child is removed while expanded, the controller keeps working and the view fades out in place when collapsed.

Accessibility

  • The child is a focusable button activated by tap, Enter or Space; set semanticLabel.
  • Focus moves into the expanded view and returns afterwards; screen readers get a dismiss action.
  • Content is not interactive and hidden from screen readers until the expansion finishes.
  • Reduced motion makes transitions instant when respectReducedMotion is on.

Performance

  • Both layers keep fixed constraints while the surface animates, so their subtrees are not re-laid out every frame; only a scale transform changes.
  • The collapsed copy stops painting after the expansion finishes.
  • backgroundBlur is the most expensive option; it is off by default.
  • No benchmark figures are published yet; profile on your target devices in profile mode.

Known limitations

  • A plain InteractiveViewer competes with drag-to-dismiss; use ExpandableAnimationZoomable instead.
  • Inherited widgets other than themes are not carried into the expanded view.
  • Dismissal is downward only.
