Expandable Animation (expandable_animation) is a Flutter package for smooth widget-to-fullscreen transitions, expandable card animations and interactive container morphing. Wrap any widget, return the expanded view from a builder, and the package morphs its position, size, corner radius and color into a fullscreen page, a centered dialog or a bottom sheet — then back again.

ExpandableAnimation(
  borderRadius: BorderRadius.circular(20),
  expandedBuilder: (context) => const ProductDetails(),
  child: const ProductCard(),
)

What you get

Transition

Container transform

Position, size, border radius and surface color interpolate together for one continuous motion.

Gesture

Drag to dismiss

Pull the expanded view down to shrink it and send it home, with velocity and distance thresholds.

Physics

Spring motion

Use duration and curve, or spring physics with optional overshoot and presets.

Layout

Fullscreen, dialog or sheet

Expand to the whole screen, a centered panel, a partial-height sheet or custom bounds.

Navigation

Back button and Escape

The expanded view is a real route: back, Escape, PopScope and focus behave as expected.

Dependencies

Flutter SDK only

No third-party runtime dependencies, no platform channels besides optional haptics.
